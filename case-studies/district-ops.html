Problem

District publishes city, county and state landing pages on two WordPress sites from Google Sheets, one row per location. Every row needs local figures: population, overdose deaths, treatment facilities and alcohol use. It also needs an infographic. The paid lookups behind those figures repeat across about 170 sheets.

How it works

The console has fifteen tools, and each names the columns it reads and writes. Local figures come from CDC WONDER and Census data, Google Places, SAMHSA directories and NSDUH. Claude with web search fills gaps and finds local news. Results are written back into the sheet itself as bold phrases, cell comments and borders, so the team never reconciles a separate report.

Pipeline stages, in order:

  1. Build the row
  2. Enrich with data
  3. Verify
  4. Ship and maintain

What it guards against

County names repeat across states. The facility cache was keyed by name, so Marion County, Florida could be served Marion County, Tennessee's facilities. 381 of 426 cache keys held more than one state's data. The fix keys entries on location and state.

Cost

Uncapped, one Claude news lookup ran 6 to 8 web searches. Capping it at two cut the cost from about $0.49 to $0.09 on three test queries, and all three still returned their five articles. On two test queries Haiku returned the same articles as Sonnet, so news runs on the cheaper model.

How I know it works

550 tests pass with the network switched off.

Stack

Python, Streamlit, Google Sheets API, Claude, Google Places, WordPress REST API, GitHub Actions.
