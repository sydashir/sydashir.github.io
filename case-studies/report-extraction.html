Problem

A battery-storage project consultancy needed the results from hundreds of supplier test reports in Excel. One supplier's reports are 12-page scans with handwritten values, red stamps and faint ruled lines. The client wanted every value that needs a human clearly marked, so I set the target as zero silent errors: no confidently wrong value that nobody is told about.

How it works

The other supplier's reports are digital, and a deterministic parser read 153 of them, 22,950 measurements, with no AI and no parse failures. For the scans, OCR finds each page by its content, grid detection cuts out every value cell, and a vision model reads the page and then each cell close up. A value is accepted when the written efficiency matches the energy readings it is calculated from, a typed serial matches the OCR text, or the page read and the close-up read agree. Printed text, tick boxes and the reviewer's name can also pass on high model confidence. Everything else is flagged.

Pipeline stages, in order:

  1. Find each page
  2. Cut out cells
  3. Vision read
  4. Close-up read
  5. Check the maths
  6. Tie-break

What it guards against

Readers that agree on the same wrong digit. The cheapest model read 36700 as 3670 at 0.98 confidence. In the delivered run both reads came from OpenAI models, and re-reading flags with the same family let wrong values through as confirmed, so flagged values also went to a model from a different vendor. Values are never accepted by majority vote. The next version accepts a value only when a free OCR engine and an OpenAI model agree, tested in simulation so far.

How I know it works

A verified answer key of 90 values scored every stage, counting silent errors separately from flagged ones. The delivered run also reached 87 of 90, but 2 of its misses were silent, digit-level misreads every reader repeated. Those cells were corrected from the answer key.

Result

71 scanned reports and 1,988 values delivered. Before delivery, 32 uncertain values were settled by two blind AI readers and a judge, and 67 flags on one reviewer's signature were standardised. On reports without verified values, expect a few percent of handwritten values to be misread in a way every reader agreed on; 2 of the 66 verified ones were. A cheaper design costs about $0.03 per report at batch prices for its first pass, against about $0.41 for the delivered run's main pass, and still needs a larger test.

Stack

Python, PyMuPDF, Tesseract, PaddleOCR, OpenAI and Claude vision models, Pydantic, Batch APIs.
