List every page

Each site is listed from its sitemap plus the WordPress REST API. A partial sitemap read is treated as untrustworthy.

Stage 2 of 6

Crawl politely

Crawled with a per-brand concurrency limit. On the throttled directory site, the limit was measured on cold pages instead of guessed:

  • Concurrency 190%
  • Concurrency 290%
  • Concurrency 330%
  • Concurrency 40%

  • 90 scooldown between crawls

Stage 3 of 6

Run 15 checks on every page

Fifteen deterministic checks run on every page, covering phone numbers that dial a sister brand, dead buttons, broken links and template fields that never got filled.

  • 1,089tests
  • 59 of 60corruption findings real when checked against the live page

Stage 4 of 6

Group repeats into one fix

Faults that repeat because they live in a shared template are grouped into one fix each, and each grouped row keeps its page count.

  • Before grouping50,438
  • After grouping35,099

Other work

87of 90 verified values read correctly

With Claude Opus 5 reading, 87 of 90, with the other 3 flagged and no silent errors.

Conventional OCR (PyMuPDF plus Tesseract) got 14 of 90 right. With Claude Opus 5 reading, 87 of 90, with the other 3 flagged and no silent errors. The delivered run also reached 87 of 90, but 2 of its misses were silent, digit-level misreads every reader repeated. Those cells were corrected from the answer key.

Battery-storage project consultancy

Handwritten test report extraction

Reads scanned, handwritten factory test reports for battery-storage containers into Excel, and flags every value it can't back up.

  • 87 of 90values right in the trial pipeline, 3 flagged
  • 1,988values delivered from 71 reports
  • 22,950digital measurements parsed with no AI

Guards against Readers that agree on the same wrong digit. Values are never accepted by majority vote, and in the delivered run flags also went to a model from a different vendor.
